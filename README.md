# prices-api

Microservicio Spring Boot para consultar el precio aplicable de un producto por fecha, brand y cadena.

## Estado actual

Este repositorio contiene solo el arquetipo inicial:

- Estructura base de Spring Boot
- Dependencias esenciales
- Configuración H2 en memoria
- Script SQL con los datos de ejemplo
- Preparación de carpetas para código y tests
